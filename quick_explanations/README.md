# Jimmy Notes

This folder is a codebase walkthrough focused on the modules outside SDK/backfill.

Suggested reading order:

1. `core.md`
2. `sdk.md`
3. `backfill.md`
4. `fetch.md`
5. `transform.md`
6. `compute.md`
7. `frontend.md`
8. `client.md`
9. `config.md`
10. `libs-and-utils.md`

What these notes try to answer:

- What the module is responsible for
- How data moves through it
- What the implementation style is
- Where the main quality risks are

These are critique notes, not formal docs. They are meant to help you build a working mental model quickly.
